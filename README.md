# ChessNavio

**ChessNavio** is a chess assistant for the browser: a suggested move and a
short idea next to the board on Lichess and other sites, game review from a
PGN, and a trainer built from your own mistakes. Analysis runs on your computer.

- **Install:** [Chrome Web Store](https://chromewebstore.google.com/detail/chessnavio/plegfgbhkjlghbpfkbihkennpjecaigd)
  — Chrome, Edge, Opera, Yandex Browser
- **Site:** [chessnavio.com](https://chessnavio.com/?utm_source=github&utm_medium=referral&utm_content=readme_en)
- **Free game review without an account:** [chessnavio.com/analyze](https://chessnavio.com/analyze?utm_source=github&utm_medium=referral&utm_content=readme_en)
- **Chess hints: where they're allowed and what you risk:** [chessnavio.com/chess-cheat](https://chessnavio.com/chess-cheat)

Check the fair-play rules of your chess site before using hints.
